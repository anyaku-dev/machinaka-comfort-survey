# 算定仕様（CALCULATION_SPEC）

算定ロジックの版：`app-calc-1.0.0`（`src/lib/calculation/types.ts` の `CALC_VERSION`）。調査開始時のスナップショット、集計確定（`round_results.calc_version`）、CSV のヘッダに記録する。

実装：`src/lib/calculation/aggregate.ts`（集計）、`src/lib/calculation/compare.ts`（比較条件）。
照合テスト：`tests/unit/excel-fixture.test.ts`（分析ツール記入例のキャッシュ値と照合）、`tests/unit/aggregate.test.ts`。

## 0. 照合の方法と結果の要約

分析ツール・記入例（`001740897.xlsx`）を openpyxl で読み、**算式**（記入用 `001740896.xlsx` と同一）と、**Excel が保存時に計算したキャッシュ値**を `scripts/extract-excel-fixture.py` で抽出し `tests/fixtures/mlit-example-v1.1.json` に保存した。アプリの算定関数に記入例の入力値を与え、キャッシュ値と比較している（許容誤差 1e-10）。

| 区分 | 状態 | 根拠 |
|---|---|---|
| 主観・活動の項目別平均（K列） | **記入例と一致** | 記入例に値のある86項目すべてで一致（独自項目欄は除く） |
| 寛容性❶ 活動の種類 1～20 の算出元 | **Excel 式と一致** | 入力① L146:L165 の式（`=MAX(...)`・単純参照）の参照行とマスタの算出元が一致（20項目） |
| 活動の種類の平均（Excel 互換値） | **記入例と一致** | 6列（L～Q）で空欄列を0として平均する Excel の挙動を再現 |
| 滞在者数・交流者数・通行者数 | **記入例と一致** | 計算_集計 C8=67, D8=45, AR8=24 |
| 1時間当たり人数 | **記入例と一致** | E8, F8, F20（人数÷計測分×60） |
| 空間A の割合・件数 | **記入例と一致** | 計算_集計 CH8～CY8 |
| 空間B の表示記号 | **記入例と一致** | 計算_集計 HX9～（1=✓、2=空欄、3=－） |
| 主観・活動の乖離「＊」 | **記入例と一致** | 計算_集計 15行目（差の絶対値≧2） |
| 要素別の「点数」・総合点 | **未検証（算出しない）** | Excel には過去調査の「点数（活動・主観の合計）」を**手入力**する欄（入力① D45:F48）しかなく、今回調査の点数を求める式が無い。記入例の値（4,5,4…）も平均値の合計とは整合しない |
| 代表値の決め方 | **公式に式なし（主催者判断）** | 手引き p.34「平均値等を参考に代表値を手動で入力」。アプリは提案値を示すだけ |
| Excel の丸め | 表示のみ | 手引き・結果シート注記「割合値・平均値は小数点以下を四捨五入により表示」。アプリは**内部値を丸めず保存**し、画面は小数2桁（割合は%1桁）で表示、CSV は丸めない |

> 「Excel と完全一致」と表示してよいのは上表で「記入例と一致」とした算式のみ。画面・CSV では各指標に「Excel照合済の算式／アプリ算出値／未検証」を表示する。

## 1. 共通ルール

- **集計対象**：既定は主催者が「採用」した提出のみ。画面で「未審査を含めた暫定表示」を選べる（CSV にも対象状態を記録）。除外・差し戻し中・入力中は含めない。
- **回答状態**（`answer_state`）：`answered`（回答。0件・評価1を含む）／`unanswered`（未回答）／`not_applicable`（適用外）／`hidden`（主催者が非表示）／`fixed`（主催者の固定値）。提出時に送られなかった設問もサーバーが `unanswered`/`hidden`/`fixed` として行を作る。
- **平均値**：`answered` と `fixed` の数値だけを平均。未回答・適用外・非表示は分母に含めない（Excel の `AVERAGE` が空欄を無視するのと同じ）。0件・評価1は値として含める。
- **代表値**：主催者が設問ごとに確定する値（`representative_values`）。状態は「値／適用外／データなし」。決め方（平均・最頻値・手入力・固定値）と根拠（平均値・回答数・対象状態）を保存し、変更は `audit_logs` に前後の値を残す。**平均値は上書きしない**。
- **提案値**（代表値の初期値候補）：4段階・件数・数値は平均値、はい/いいえ/不明は**最頻値**（同数なら提案なし＝主催者判断）、固定値があれば固定値。

## 2. 指標の定義

各指標：入力元／対象と除外／式／単位／丸め／未回答時／複数調査者／Excel 照合／比較可能な条件。

### 2.1 居心地の良さ（主観・活動）項目別平均
- 入力元：`answers`（scale4）。対象：採用提出。除外：未回答・適用外・非表示。
- 式：Σ値 ÷ 回答数。単位：点（1～4）。丸め：なし（表示2桁）。
- 未回答時：回答数0なら null（「—」）。複数調査者：調査者別の原回答を保持し平均。
- Excel：入力① K列 `=IFERROR(AVERAGE(L:Q),"")` と一致。
- 比較条件：設問の表示構成・夜間計測・時間帯が同じこと。

### 2.2 寛容性❶ 活動の種類（1～20：自動算出）
- 入力元：マスタの `computed_from`（Excel 入力① L146:L165 の式の参照先）。
- 調査者ごとの値：算出元のうち `answered`/`fixed` の値の**最大値**。算出元が全て未回答・適用外なら値なし。
- アプリ平均：値のある調査者だけで平均（2.1 と同じ欠測処理）。
- **Excel 互換値（参考）**：Excel は `IFERROR(MAX(...),"")` が空欄に対して 0 を返し、それを `AVERAGE(L:Q)`（6列）で平均するため、**調査者が6人未満でも空欄列が0として分母に入る**（記入例：5人とも4 → Excel 3.33）。アプリは参考値として同じ計算（Σ値÷6、6人以下のときのみ）を表示・CSV 出力するが、代表値の提案には使わない。この差は DECISIONS.md D-08 参照。
- 「遊んでいる」（KAN-T01）の式は主観行を参照しており他と不整合 → **未検証**バッジ表示。
- 21～23（勉強・絵・ボードゲーム）と独自の活動の種類は調査者が直接入力（4段階）。

### 2.3 空間B（機能・設え）
- 入力元：`answers`（ynu3：1はい／2いいえ／3不明）。平均はしない（名義尺度）。
- 代表値提案：最頻値（同数なら主催者判断）。表示：1=✓、2=□（Excel は空欄）、3／未確定=－。Excel 計算_集計 HX9 の式 `=IF(x=1,"✓",IF(x=2,"","－"))` と一致。
- 適用条件：24～31（回遊）は活用の手引きで「ストリート限定」→対象地種別がストリート以外の場合は初期状態で非表示。7 は 6 に依存（適用外を選択可）。

### 2.4 空間A（沿道建物・土地）
- 入力元：各調査者の件数（`space_counts`）。調査者間の代表値は主催者が確定（提案は平均値）。**指標は確定した代表値から算出**（Excel も J 列の代表値から計算）。必要な項目の代表値が未確定なら算出しない（理由を表示）。
- 式（Excel 計算_集計と同じ）：
  - 建物 利用の割合 = (A01～A09) ÷ (A01～A10)　[CH8]
  - 建物 未利用の割合 = A10 ÷ (A01～A10)　[CI8]
  - 見やすい割合 = (A01,A02,A04,A05,A07,A08) ÷ (A01～A09)　[CJ8]
  - 見にくい割合 = (A03,A06,A09) ÷ (A01～A09)　[CK8]
  - 屋外の滞留空間ありの建築数 = A01+A04+A07　[CL8]
  - 土地 活用の割合 = (A11+A12) ÷ (A11～A13)　[CW8]
  - 土地 未活用の割合 = A13 ÷ (A11～A13)　[CX8]
  - イベント実施数 = A11　[CY8]
- 分母0：null（Excel は #DIV/0!）。

### 2.5 滞在者・通行者
- 入力元：`observation_groups`（グループ単位）。対象：採用提出のうち「人数集計に含める」がオンの提出。
- 人数：グループ人数の合計。**Excel は性別内訳の合計を人数としている**（計算_集計 C8=SUM(E:G)）。アプリはグループ人数を明示入力し、表示している属性の内訳合計がグループ人数と一致することをサーバーで強制するため、性別を表示している限り同値になる。
- 交流者数 = 滞在のうち 1人以外（家族・グループ・団体）の人数（D8、手引き「二人以上で滞在していた人」）。
- 1時間当たり人数 = 人数 ÷ 計測分数 × 60（E8, F8, F20）。**計測分数が未設定・0以下なら算出しない**（null と理由を表示）。単位：人/時間。丸めなし。交流者は滞在者の計測分数を使う。
- 滞在者割合 = 滞在/時 ÷ (滞在/時 + 通行/時)（K19）。どちらかの計測分数が無ければ算出しない。
- 属性割合 = 属性人数 ÷ 同区分の記録人数合計（P8 等）。属性を非表示にしたグループは「未記録」として分母から除き、その人数を併記する。行動（スタスタ／のんびり）は通行者のみ。
- **複数調査者**：Excel は1枚の観察シートを前提とする。アプリは採用提出の観察を合算し、2名以上から集まった場合は「同じ人を重複して数えていないか」警告を出す。分担（例：滞在担当と通行担当）以外の重複は、主催者が提出ごとに「人数集計に含める」を切り替えて調整する（D-06）。

### 2.6 主観と活動の乖離
- 同じ要素・同じ番号の主観と活動の値の差の絶対値が2以上なら「＊」（計算_集計 15行目、手引き p.40「2点以上乖離」）。
- 値は代表値を優先し、未確定なら提案値（平均）を使って「未確定値を含む」と表示。

## 3. 比較（過去回）

- 比較対象：同じ調査の、開始済みで回番号が小さい直近3回（Excel の「過去調査①～③」に相当）。
- 値：各回の**最新の確定版**（`round_results.payload`）。未確定なら採用提出からの暫定集計（「暫定」と表示）。
- 比較条件の差異として表示する項目：滞在者・通行者の計測時間、開始時刻の差が60分超、平日／休日（土日・祝日フラグ）、夜間、イベント、天候（開始・終了）、範囲の文章3種、設問マスタの版、算定ロジックの版、表示した設問の差、確定の有無。
- 1時間当たり人数は計測時間が異なっても換算後の値で並べるが、計測時間の差は必ず差異として表示する。

## 4. CSV

| 種類 | 内容 |
|---|---|
| 集計（summary） | 設問別の回答数・未回答・適用外・非表示・固定値・平均値・最頻値・代表値（状態・値・決め方・メモ）、活動の種類（アプリ平均・Excel互換値）、指標（値・式・根拠・検証状態・算出しない理由）、乖離判定 |
| 原回答（raw） | 提出（入力中以外）× 設問の全行。回答状態・数値・文字・選択肢ラベル・提出状態・版 |
| 滞在者・通行者（observations） | グループ単位の原記録、属性（非表示は「記録なし」）、人数集計に含めるか |

- UTF-8 BOM 付き・CRLF。先頭が `= + - @ タブ CR LF`（全角＝＋－＠を含む）の文字列は `'` を前置して数式として解釈されないようにする。数値型（負数を含む）は数値のまま出力。
- ヘッダ行に調査名・回・調査日・算定ロジック版・スナップショットハッシュ・出力日時を記録。
